# Website typography

Font families verified from the HTML, CSS and computed styles at
https://www.viettelup.vn/internet on 2026-10-21.

The reference uses Beau Sans for Internet headings and package names, and Sarabun
for navigation. This project also uses Sarabun for body copy and form controls.
Files are served locally so rendering does not depend on the reference website.
